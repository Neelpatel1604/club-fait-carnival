# AWS Carnival

Next.js carnival midway for the Sheridan AWS Student Builder Group club fair.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Prizes

Ticket thresholds live in `src/lib/data.ts` (`prizes` array). Default ladder:

| Prize | Tickets |
| --- | --- |
| Stickers | 4 |
| Custom button | 8 |
| Club diary | 14 |
| Tote bag | 22 |

Players show their ticket count at the booth to redeem.
